Политика конфиденциальности SOPKA

Дата вступления в силу: 7 сентября 2026 года

SOPKA — велокомпьютер, который записывает поездки на Android-устройстве пользователя. В приложении нет рекламы и аналитических SDK, для работы не требуется аккаунт приложения.

Какие данные обрабатываются

В зависимости от используемых функций и выданных разрешений приложение обрабатывает:

  • точное местоположение, маршрут, скорость, высоту и время поездки;
  • ЧСС, скорость колеса и каденс с подключённых датчиков;
  • введённые пользователем данные велосипедиста: вес, возраст и измеренную максимальную ЧСС;
  • настройки приложения и сохранённую историю поездок;
  • версию приложения, версию Android и модель устройства, только когда пользователь добровольно добавляет техническую информацию в обращение.

История, настройки датчиков и данные велосипедиста хранятся локально. У приложения нет собственного аккаунта или облачной базы разработчика.

Внешние сервисы

При использовании соответствующих функций SOPKA может обращаться к:

  • OpenFreeMap для отображения карт — сервис получает IP-адрес и запрошенную область карты;
  • OpenTopoData для получения высоты — сервис получает необходимые координаты и IP-адрес только после явного согласия в разделе «Настройки → Конфиденциальность». Функция по умолчанию выключена; её можно отключить в любое время;
  • GitHub, когда пользователь открывает страницу проекта или добровольно создаёт обращение.

Эти сервисы обрабатывают данные по собственным правилам. SOPKA не продаёт персональные данные и не передаёт их для рекламы.

Резервное копирование Android

Если пользователь включил резервное копирование Android, поддерживаемые настройки и история поездок могут быть переданы службе резервного копирования, связанной с аккаунтом устройства. Этим управляют Android и пользователь. Адреса датчиков и временные файлы исключены из настроенного облачного копирования.

Хранение и удаление

Данные остаются на устройстве, пока пользователь не удалит поездки, не очистит данные приложения или не удалит приложение. Резервная копия Android может храниться согласно настройкам её провайдера. Экспортированные вручную файлы находятся под контролем пользователя.

Локальная диагностика высоты по умолчанию выключена. При включении сохраняется не более четырёх файлов размером до 2 МиБ каждый. Файлы старше семи дней удаляются при следующей записи журнала. В разделе «Настройки → Конфиденциальность» можно отключить диагностику и удалить её журналы. Идентификаторы датчиков удаляются из новых экспортов истории и облачных копий. Ранее выгруженные файлы и уже сохранённые провайдером резервные копии задним числом не изменяются.

Разрешения

Геолокация нужна для записи маршрута и показателей поездки. Разрешения Bluetooth нужны для поиска и подключения поддерживаемых датчиков. Уведомления используются для статуса активной поездки и предупреждений.

Дети

Приложение не предназначено специально для детей младше 13 лет.

SOPKA Privacy Policy

Effective date: September 7, 2026

SOPKA is a cycling computer that records rides on the user's Android device. The app does not contain advertising, does not use analytics SDKs, and does not require an application account.

Data processed by the app

Depending on the features used and permissions granted, SOPKA processes:

  • precise location, route, speed, altitude and ride timestamps;
  • heart-rate, wheel-speed and cadence readings from connected sensors;
  • rider data entered by the user, such as weight, age and measured maximum heart rate;
  • app preferences and saved ride history;
  • app version, Android version and device model when the user voluntarily includes technical information in a feedback message.

Ride history, sensor settings and rider data are stored locally on the device. The app has no developer-operated account or cloud database.

External services

SOPKA may contact the following services when their related features are used:

  • OpenFreeMap map and tile services to display maps. Network requests disclose the device IP address and the requested map area to the service;
  • OpenTopoData to obtain elevation data. The coordinates needed for the request and the device IP address are sent to that service only after explicit consent in Settings → Privacy. This feature is off by default and can be disabled at any time;
  • GitHub when the user opens the project page or voluntarily creates a feedback issue.

These services process data under their own privacy terms. SOPKA does not sell personal data or share it for advertising.

Android backup

If Android backup is enabled by the user, supported settings and ride history may be copied by Android to the backup service associated with the device. This transfer is controlled by Android and the user's device account. Sensor addresses and temporary files are excluded from the configured cloud backup.

Retention and deletion

Data remains on the device until the user deletes rides, clears the app's data, or uninstalls the app. Android may retain a device backup according to the user's backup provider settings. The app also provides manual export and restore of ride history; exported files remain under the user's control.

Optional local elevation diagnostics are off by default. When enabled, logs are limited to four files of up to 2 MiB each. Files older than seven days are removed when logging next runs. Settings → Privacy lets you disable and delete these logs. Sensor identifiers are removed from new history exports and cloud backups. Older copies already exported or stored by a backup provider are not retroactively changed.

Permissions

Location is used to record rides and provide ride metrics. Bluetooth permissions are used only to discover and connect supported cycling and heart-rate sensors. Notification permission is used for active-ride status and alerts.

Children

SOPKA is not directed to children under 13.
